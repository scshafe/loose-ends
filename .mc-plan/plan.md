# Loose Ends Implementation Plan

Build Loose Ends in eight shippable phases from §15 of `LOOSE_ENDS_PLAN.md`. The CLI should become usable after Phase 15.3, with later phases layering lifecycle controls, hierarchy, tags, polish, and service installation.

Acceptance criteria:
- Preserve the phase order from the spec.
- Keep each phase independently reviewable and shippable.
- Avoid app scaffolding or Go implementation until the operator explicitly starts Phase 15.1.
