Phase 15.1 scaffolding is intentionally thin: one `loose-ends` binary entrypoint delegates to an internal Cobra CLI package, and TOML config read/write behavior lives in `internal/config` so later CLI and service phases can share it. The default config follows the locked spec values, including loopback URL `http://127.0.0.1:17890` and database DSN text only; no database connection or service startup was attempted. Baseline dependencies were pinned to versions compatible with the available Go 1.23.4 toolchain.
